# Master VIP local fonts

Nunito Sans sources: google/fonts, ofl/nunitosans/NunitoSans[YTLC,opsz,wdth,wght].ttf and NunitoSans-Italic[YTLC,opsz,wdth,wght].ttf.
Quicksand source: google/fonts, ofl/quicksand/Quicksand[wght].ttf.
Downloaded 2026-10-26 through GitHub. SIL OFL licenses are included next to these files.

Static instances generated with fontTools.varLib.instancer. Weight 400 for body/italic, 700 for bold, 600 for display. Nunito Sans optical size 12; other axes at source defaults. Display derivative renamed SIYAYO Display to respect the Reserved Font Name Quicksand. CSS alias Quicksand identifies the existing visual role. Glyph shapes retain the instantiated source design. Each static instance has its own PostScript name for correct PDF embedding. Original copyright statements are retained in font files.
