# JAGUAR H14.18 — FUNC-13 · Function Window / Context Snapshot

**MARCO:** The module remains **hidden in normal Explorer navigation**. This is an independent design laboratory, not an upgrade to verb-explorer.html or the deployed site. The final placement of FUNC-13 in Explorer HTML is UNDECIDED, subject to human homologation. No new evaluation, PATITA writes, Word Path changes or audio controls.

## Ownership model
Gear Stack governs LANGUAGE, TENSE, MODE, WORD TYPE and PERSPECTIVE; Experience Navigation governs the scene. Thinking Mind QW is optional. The FUNC-13 only chooses **QUALITY / STATE / MOVEMENT / ACTION / EXISTENCE** and asks a read-only projector to interpret the current context. It never repeats the TENSE or MODE controls in the intended final module.

PERIOD is **not present as an independent gear** in current Explorer markup. Snapshot.period is `null`, annotated `UNAVAILABLE_IN_CURRENT_GEAR_STACK`. It must not be mapped silently to a completed-period tense or treated as an established period exercise. Integration will need a separate decision for PERIOD.

## Three semantic surfaces inside one full-width Window
1. **FUNCTION** — original Master VIP source pattern and direct original example if available in the current language, plus a clearly labeled SIYAYO adaptation candidate. The Master source index has EN/PT examples; an ES source example is not invented.
2. **CONTEXT / PERSPECTIVE** — canonical S1–S4 authored lines in EN/ES/PT, colors red/yellow/green/blue. No active Perspective uses DESCRIBING for **display only**, without changing Explorer state.
3. **FINE STUDY** — H14.9 review status and its reason. 1 SOURCE_CLOSE + 57 BRIDGE + 22 CONTRAST are initial study opinions, not learner scores, canonical task answers or assessment permissions.

In the independent prototype, Gear Stack is **simulated** for testing; the final module will use a read-only Context Snapshot from the Explorer instead of creating duplicate selectors. Function buttons are arranged in a horizontal, scrollable strip. The Window occupies the full module width and uses three panels on desktop, one column in portrait.

## Pedagogical and safety invariants
Master VIP MOVEMENT = TO BE + VERB-ING, not synonymous with physical displacement. ACTION habit claims remain unverified until the Experience explicitly establishes routine. EXISTENCE = THERE + TO BE (independent function, never a mandatory QW). Incorrect or unauthored TENSE/MODE/PERIOD transformations never appear as evaluated answers. Human review must account for Spanish and Portuguese SER/ESTAR versus English TO BE.

Review provenance remains visible; no invented contextual responses, scoring, attempts, persistence, speech or learner progress. A selected Function can be retained in ephemeral per-Experience local prototype state; its selection never modifies Gear Stack/PATITA.
