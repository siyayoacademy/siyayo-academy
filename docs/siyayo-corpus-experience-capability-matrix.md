## Reading rule

This matrix answers the four canonical questions for the **Ten Kinds of Words + Question Words**:

**WHAT EXISTS? → WHAT IS MISSING? → WHAT CONNECTS? → WHERE NEXT?**

Status means integration maturity, not pedagogical importance:

- **GREEN** — canonical Chapter plus an operational runtime/corpus connection exists.
- **YELLOW** — canonical Chapter exists and the integration contract is clear, but reusable runtime corpus/evidence is incomplete.
- **OPEN** — reserved work remains before the capability can participate fully in Experiences/adaptation.

## Cross-system findings

### 1. The project is not missing “content” in one undifferentiated sense

There are three different gaps and they must not be mixed:

```text
A. CHAPTER / A5 CONTENT
   largely canonical and ready

B. REUSABLE CORPUS
   strong for VERBS, NOUNS and ADJECTIVES;
   incomplete as dedicated corpora for the other kinds

C. OPERATIONAL SKILL / EVIDENCE
   strongest around verb-function and selected Question Word behavior;
   not yet symmetrical across the Ten Kinds
```

Therefore the next work is **not** to rewrite all Chapters. It is to promote canonical Chapter/MASTER knowledge into reusable corpora and observable capabilities only where Experience needs it.

### 2. Thinking Mind is a cross-cutting information-need engine

Current Experience seeds prove that Thinking Mind is already broader than WHAT/WHERE:

- `shopping-for-dinner`: WHAT, WHERE, HOW MUCH, WHICH, WHY, WHO.
- `preparing-dinner`: WHAT, WHERE, WHEN, HOW, WHICH, WHY, WHO.
- later dinner Experiences continue WHAT/WHO/HOW/WHY.
- College Experiences also contain contextual Question Words.

The canonical target remains **14 Question Words**, selected by contextual information need. WORD TYPE must remain a separate axis: a Question Word focus does not mean that the selected lexical item is itself one of only fourteen words.

### 3. The strongest current vertical slice

```text
Question Word
    ↓
Thinking Mind
    ↓
Verb / Noun / Adjective
    ↓
Lexical Composition
    ↓
Tense + Mode
    ↓
Language
    ↓
Perspective
    ↓
Question → Response → Follow-up
    ↓
Attempt / Evidence
    ↓
WAIT or GREEN
    ↓
NEXT
```

This should become the **reference integration pattern** for the remaining word types rather than building ten unrelated mini-apps.

### 4. MASTER must feed capabilities, not duplicate A5

The canonical direction is:

```text
A5 = map
MASTER = depth
CORPUS = reusable structured knowledge
EXPERIENCE = contextual application
EVIDENCE = observed learner action
```

A MASTER item is promoted into runtime corpus only when an Experience, diagnostic, comparison, speech/listening activity or adaptive skill needs it.

### 5. First missing contract discovered

Chapter 01 NOUN is the only audited Ten-Kinds Chapter without the explicit `chapterScope` / `masterScope` contract now present in Chapters 02–10. Its content and integration links exist, but this metadata gap should be closed before broad noun expansion.

## Admission protocol for every new corpus item

A runtime corpus item must declare or inherit:

```text
word kind
canonical meaning
EN / ES / PT forms
semantic/function tags
source/depth role
Experience contexts
Question-Word affinity when relevant
composition/dependency role when relevant
observable learner action
evidence skill or NONE
speech role
visual role
WAIT/NEXT behavior
```

This is the guard against fragmentation: content is admitted because a canonical capability needs it, not because another isolated list can be created.
