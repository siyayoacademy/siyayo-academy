## Seven minimum cross-project contracts

1. Identity: objective, audience, purpose, boundaries and owner.
2. Data: canonical content, source, provenance, languages, rights, version and asset references.
3. Logic: rules, functions, state, events, dependency and runtime authority.
4. Visual experience: how-to-show, accessibility, portrait/landscape, motion and responsive L0–L3 surface.
5. Integration: shared interfaces, APIs, contracts and reusable components without duplicate authorities.
6. Validation: tests, acceptance criteria, audit, regressions and human approval.
7. Evolution: decisions, discoveries, open questions, migration and next steps.

## Data/content versus presentation

Informational modules manage PDF, A5, MASTER, hymnals, image/media banks, sources, text, video, audio, speech and structured content. Presentation modules implement how-to-show. Some share a relatively common presentation grammar (Dependency Focus, Lines / Possible Responses); others require specialized interaction engines (Pianinho Mágico, Frondosa, Fine Art). Do not collapse data ownership into rendering code.

## MVR-FA-001 — Fine Art preservation and layer contract (PROPOSED)

Preserve by default; change only explicitly requested elements. Record original immutable asset, license/access rights, checksum, provenance, transformation history and output lineage. Inventory all meaningful objects and context: portrait/identity, clothing, flag, hat, staff, landscape, emblems, symbols, text, geometry, texture, colors and relative placement. Each extracted asset must have independent transparent RGBA image or mask, explicit canvas dimensions, original bounding box, normalized coordinates, anchor, z-order, group, opacity, transform, crop/safe-area constraints, visibility and preservation rules. A common transparent square workspace may be used for extraction, but must not erase the original aspect ratio or geometric position. Distinguish square layer canvas from the actual flag rectangle. Alpha transparency must ensure empty regions do not cover lower layers.

A Brazilian flag reconstruction example must preserve green field, yellow diamond, blue disc, stars, white band and motto as separately identifiable aligned elements. A portrait/landscape recomposition may relocate the Master, flag, cabin, lake and forest only under explicit instructions; missing or distorted protected elements fail validation. JSON describes semantics/geometry but cannot by itself recover pixels or guarantee perfect segmentation. Store original, masks, layer assets, compositing manifest, previews and visual QA results. Include text/symbol fidelity checks and a manual approval gate for culturally or spiritually important images. No generative editing of protected elements by default.
